Lua scripting

Three of the showcase windows are complete applications written in interface data alone, with no game code in the sample binary:

  • Minesweeper - 81 template-stamped cells driven through reflected widget properties.
  • Lua console - a REPL over the live widget tree; pairs() walks reflected widgets like tables.
  • Inventory - real drag-and-drop gestures polled from a per-frame tick via getMousePos/getMouseDown.

The embedding contract

The embedder calls initLUA before parsing so stock bindings exist at parse time, and registers the environment hooks the client would normally provide: getUI, the mouse pollers, and the browse action handlers this very window uses.
